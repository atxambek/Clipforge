# Telefon orqali APK yig'ish
1. GitHub'da private repository yarating.
2. `ClipForgeAI-Android` ichidagi barcha fayllarni, yashirin `.github` papkasini ham, repository ildiziga yuklang.
3. GitHub → Actions → Build ClipForge AI APK → Run workflow.
4. Build tugagach Artifacts'dan `ClipForgeAI-debug-apk` ni yuklab oling.
5. Ilovaga backend HTTPS URL va API access tokenni kiriting.
